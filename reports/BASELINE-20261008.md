# 검증 결과

원본 `4e96da0b7e31831ee97aaef153b2bef977a235e1`에서 전략 소스를 바꾸지 않고 VS2022 v143 / SDK 10.0.26100.0 / Win32 Release 빌드에 성공했다. 결과 DLL SHA256은 `292aaefeadf2a0adbd3d60065188e5194d93266a63e1d1542ce840261e3e6b0c`다. 반복 실행 가능한 PowerShell 빌드 스크립트로 같은 해시를 확인했다.

- 네이티브 검사: DLL 로드, gameInit/newAIModule 내보내기, 생성·소멸 통과. 게임 onStart/onFrame은 미실행.
- 자료 연결: 1,645개 모두 보존(PvP 285 / PvT 697 / PvZ 663). 사용자 확인에 따라 2500+ 코호트로 받아들이며 MMR 제외 0개.
- 상태 추출: 기존 세대 불일치 0인 자료 1,582개, 불일치 61개, 추출 오류 2개. 첫 8분 교차 비교 자료 986개. 이 수는 MMR 검증 결과가 아니다.
- 분석/평가 분리: 기존 1,307 / 338개를 보존. 같은 PvP 경기의 양쪽 관점도 같은 분리 안에 둔다.
- 실제 자료 조회: 동일 맵 해시에서 TwoGate3Zealot, Nexus23, NineGateExpand 각각의 분석용 사례를 4,000프레임 시점으로 조회했다. 각 조회의 상황·빌드 후속 관측을 로컬 data/smoke-*.json에 저장했다.
- 회귀 검사 7개 통과: 등급 메타데이터가 없어도 양쪽 PvP 관점 유지, 평가 자료/다른 맵/다른 빌드 제외, 원본 변조 및 캐시 잘못 연결 차단, 교차 비교 시간 범위, 미래 상태 참조 금지, 경로 범위 검사.
- 현재 9맵 CHK 해시가 기존 맵 목록과 일치. BWTA 버전 6 캐시는 9개 모두 없어 사전 점검은 의도대로 실패했다. 위치·길목·경로의 실제 정확성을 검증한 것이 아니다.

리플레이 검색과 기준 빌드 준비가 완료된 상태이며, 행동 모방 학습이나 정책 개선, Remastered 실전 구동·승률·MMR 향상은 아직 주장하지 않는다. 사용자가 종료한 래더 실행과 재생 중인 리플레이에는 개입하지 않았다.
