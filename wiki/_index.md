# NNB

사용자는 Stardust 전략 개조를 중단하고 Locutus 포크를 NNB(NewNimdalBot)로 개발하도록 지시했다. 기존 Nimdal의 리플레이·에디터·실험 기록은 보존한다. 논리적인 Nimdal 프로젝트의 후속 작업이다.

현재 기준과 재현 명령은 [NNB.md](../NNB.md)에 둔다. 순정은 고정된 upstream 소스를 별도로 추출해 빌드하며, 편집용 소스와 DLL을 구분한다. 초기의 9맵 BWTA 캐시 부재는 해소됐다. 게임 초기화·실제 경기 성능은 아직 검증하지 않았다.

구체적인 검사 결과와 한계는 [초기 검증 기록](../reports/BASELINE-20261008.md)에 둔다.

현재 [전략 에디터](../reports/EDITOR.md)는 종족전별 오프닝, 생산 순서, 운영 수치, 조건·행동·우선순위·유지 방식과 근거 메모를 편집한다. 실제 C++ 규칙 엔진 미리보기와 독립 실행본 생성까지 연결했다. [맵 지형 분석](../reports/MAPS.md)은 9맵의 기지·길목·거리와 검증 범위를 기록한다. 에디터 저장이나 DLL 생성 성공을 경기력 검증으로 표현하지 않는다.

[연결 영향 검사](../reports/EDITOR-SAFETY.md)는 선행 생산·가스·규칙 충돌·순정 전환을 검사하고, 변경 미리보기와 저장본 복원을 제공한다. 정적 오류가 있는 활성 프로필은 서버에서도 시험본 생성을 막는다. 실제 경기 성능은 계속 미검증이며, 연결 항목을 함께 고쳤다는 이유만으로 성능 보존을 보장하지 않는다.

2500+ 수집 조건은 사용자 제공 사실로 받아들이며 MMR 재검증이나 재필터링을 하지 않는다. 기술적인 리플레이 식별·재생 오류와 평가용 분리만 점검한다. 개선은 같은 맵·같은 빌드·유사한 상황의 행동 근거에 따른다.

사용자는 순정 무제한 APM 래더 시험을 종료하고 현재 재생 중인 리플레이를 유지하도록 지시했다. 게임 종료·재시작·추가 매칭과 기존 자동화 재개를 하지 않는다. 후속 실행은 새 사용자 지시에 따른다.

[결정 후보](inbox.md)는 장기 재사용 문맥이고, 데이터와 기기별 경로는 버전 관리에서 제외한다.
