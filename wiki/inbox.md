## 2026-10-08 — 수집된 고수 리플레이의 자격

- status: ready
- fingerprint: nnb-accept-collected-2500-cohort
- occurrences: 1
- last_seen: 2026-10-08
- 근거: 사용자는 최초 수집 때 MMR 2500+로 제한했으므로 이 조건을 재검증하지 말라고 명시했다.
- 적용: 전량을 해당 코호트로 받아들이고 재생 오류·동일 맵/빌드/상황 대응에 집중한다. MMR 불명인 PvP 상대를 별도 제외하지 않는다. 이는 추출 상태가 정확하다는 의미는 아니다.
- 반영: corpus importer는 등급 메타데이터를 읽거나 필터에 사용하지 않는다. 위키 현재 문맥은 사용자 지시를 직접 따른다; 전역 규칙으로 승격하지 않는다.

## 2026-10-08 — 순정 보존과 직접 편집

- status: ready
- fingerprint: nnb-user-editable-policy-preserve-pure-build
- occurrences: 1
- last_seen: 2026-10-08
- 근거: 사용자는 현재 시즌 지형을 분석하고, 순정을 남긴 채 오프닝·운영·판단 구조와 고려 사항을 직접 수정할 에디터를 요청했다.
- 적용: 순정과 편집본은 별도 소스 빌드·DLL·프로필로 구분한다. 조건과 행동에는 실제 실행 연결·적용 범위·근거 메모를 제공한다. 지원하지 않는 마이크로를 설정만으로 구현했다고 표현하지 않는다.
- 반영: 읽기 전용 기준본, 복사본 편집, 고정 오프닝, 조건 규칙, 미리보기, 출처와 해시를 확인하는 실행본 생성. 프로젝트 전용 결정이며 전역 규칙으로 승격하지 않는다.

## 2026-10-08 — 연관된 판단의 영향과 회귀 방지

- status: ready
- fingerprint: nnb-editor-coupled-change-regression-guards
- occurrences: 1
- last_seen: 2026-10-08
- 근거: 사용자는 일부 개선이 다른 분기를 망가뜨리지 않도록 연결된 요소를 에디터에 반영하라고 요청했다.
- 적용: 같은 개선에 필요한 선행 생산·경제·정찰·전투·배치 영향을 함께 검토한다. 알려진 충돌은 시험본 생성을 차단하고, 근거 없는 일괄 수정이나 검사 통과를 경기력 보장으로 표현하지 않는다.
- 반영: 변경 영향 검사, 선행 순서 수정 미리보기, 규칙 우선 관계 명시, 서버 차단, 버전 보존·복원, 오프라인 후보 표시. 검사 계약과 확인된 파서 문제는 reports/EDITOR-SAFETY.md에 모았다. 프로젝트 전용 후보다.

## 2026-10-09 — 읽을 수 있는 오프닝과 순정 판단에서 시작하는 편집

- status: candidate
- fingerprint: nnb-readable-opening-native-judgment-editing
- occurrences: 1
- last_seen: 2026-10-09
- 근거: 사용자는 빌드 약어·부분 번역된 명령을 이해하기 어렵고 빈 조건 규칙을 만드는 것보다 기존 순정 판단과 정찰 전략 추정을 보고 수정하고 싶다고 교정했다.
- 적용: 게임 용어의 뜻·실행 시점·기존 기준을 한국어로 보여주고, 원문은 고급 편집에 둔다. 실제 작동하는 판단과 비활성 분기, 설명만 가능한 부분과 편집 가능한 값을 구분한다. 추정 기준 변경의 후속 영향과 기본값 보존을 함께 검증한다.
- 반영: 세부 의미·관측 시간의 추정 방식·회귀 검사는 reports/JUDGMENTS.md에 기록했다. NNB 전용 후보이며 전역 지침을 변경하지 않는다.
